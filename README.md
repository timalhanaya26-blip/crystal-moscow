# 🏨 روسيا هوتيلز — منصة حجز فنادق

موقع حجز فنادق عربي كامل (RTL) مبني بـ **Next.js 14 + TypeScript + Tailwind CSS + Prisma (SQLite)**.

## ✨ المميزات

- **الصفحة الرئيسية**: واجهة جذابة + قسم الفنادق الفاخرة + قسم الفنادق الاقتصادية + الأسئلة الشائعة.
- **صفحة كل الفنادق** (`/hotels`): فلترة حسب المدينة، التصنيف، النجوم، والترتيب حسب السعر/التقييم، مع ترقيم الصفحات.
- **صفحة تفاصيل الفندق** (`/hotels/[slug]`): ألبوم صور، المرافق، قائمة الغرف (السعر، المساحة، السعة)، ونموذج حجز.
- **نظام حجز كامل**: نموذج إدخال بيانات العميل يُخزّن الحجز في قاعدة البيانات + رابط واتساب جاهز بتفاصيل الحجز.
- **لوحة الحجوزات** (`/admin/bookings`): عرض كل الحجوزات الواردة.
- **صفحة من نحن** (`/about`) و **الأسئلة الشائعة** (`/faq`).
- **تذييل** بروابط التواصل ووسائل التواصل الاجتماعي + **زر واتساب عائم**.
- تصميم عربي RTL بالكامل بخط Cairo، متجاوب مع الجوال، وسريع التحميل.

## 🚀 التشغيل

```bash
npm install        # تثبيت الحزم (مرة واحدة)
npm run db:reset   # إنشاء قاعدة البيانات وملؤها بالبيانات
npm run dev        # تشغيل وضع التطوير على http://localhost:3000
```

للنشر (الإنتاج):

```bash
npm run build
npm run start
```

## 📝 إضافة فنادقك الحقيقية

كل بيانات الفنادق في ملف واحد: **`prisma/seed-data.ts`**

1. افتح الملف وعدّل قائمة `HOTELS` — انسخ أي فندق موجود وعدّل قيمه.
2. للصور: ضع صورك في مجلد `public/images/` واستخدم مسارًا مثل `"/images/hotel1.jpg"`، أو استخدم روابط خارجية.
   - إن استخدمت رابطًا خارجيًا، أضف اسم النطاق في `next.config.mjs` ضمن `remotePatterns`.
3. لإيقاف توليد الفنادق التجريبية: في `prisma/seed.ts` غيّر `TARGET_TOTAL` إلى `HOTELS.length`.
4. أعد ملء قاعدة البيانات:

```bash
npm run db:reset
```

## ⚙️ إعدادات الموقع

- **اسم الموقع، رقم واتساب، روابط التواصل، البريد**: في `src/lib/site.ts`
- **الأسئلة الشائعة**: في `src/lib/faq.ts`

## 🗂️ بنية المشروع

```
prisma/
  schema.prisma     # مخطط قاعدة البيانات (فندق، غرفة، حجز)
  seed-data.ts      # ← بيانات الفنادق (عدّلها ببياناتك)
  seed.ts           # سكربت تعبئة قاعدة البيانات
src/
  app/
    page.tsx              # الصفحة الرئيسية
    hotels/page.tsx       # قائمة الفنادق + الفلاتر
    hotels/[slug]/page.tsx# تفاصيل الفندق + الحجز
    about/ faq/           # صفحات ثابتة
    admin/bookings/       # لوحة الحجوزات
    api/bookings/route.ts # واجهة إنشاء الحجز
  components/             # المكوّنات (الترويسة، التذييل، البطاقات، النموذج...)
  lib/                    # إعدادات الموقع ودوال الوصول للبيانات
```

## 🔁 الترقية لـ PostgreSQL لاحقًا

غيّر `provider` في `prisma/schema.prisma` إلى `postgresql` وحدّث `DATABASE_URL` في `.env`، ثم `npm run db:push`.

## 🔒 ملاحظة أمنية

لوحة `/admin/bookings` غير محمية بكلمة مرور حاليًا — أضِف تسجيل دخول قبل النشر الفعلي.
